# 事实库规范（全体 subagent 必读，必须逐条遵守）

## 0. 调查对象与口径
- 对象：**史蒂夫·保罗·乔布斯 / Steve Jobs（1955-02-24 ~ 2011-10-05）**，苹果公司（Apple Inc.）联合创始人、前 CEO；亦涉 NeXT、Pixar、迪士尼董事。
- 口径（用户 2026-11-04 确认，算 L0 级授权）：**只查公开信息**；**保持绝对中立、不偏不倚**；允许写公开可查的负面与争议；允许引用社媒/论坛/匿名帖但必须标 L3，且一律不得进入"事实定稿"；需要英文/外文原始来源。
- 用途：中立全景人物档案（非谈判/非采访准备）。英文原文务必保留（人物姓名、作品名、术语均给英文原文）。

## 1. 【绝对禁令】
严禁产出：谈话稿、采访提纲、谈话地图、现场追问设计、手卡、问题清单型访谈设计。一句话都不行。质检项 Q12 出现即整份不通过。若任务描述里出现"你想问什么"一律不做。

## 2. 置信等级（唯一标准，不得自创）
- **L0**：原始来源已核实（官方讲稿全文 / 官方新闻稿 / SEC 文件 / 法院卷宗 / 官方视频页面 / 本人署名的原始文本），且引文可与原文逐字对照；或用户明确确认。
- **L1**：多个独立可靠来源一致（≥2 个互不隶属的权威媒体/传记/档案），但未回到原始源逐字核验。
- **L2**：单一来源（含 Isaacson 授权传记等单一权威文本）、或基于已核事实的合理推断（推断必须显式标"推断"）。
- **L3**：说法互相矛盾 / 弱来源（社媒帖、论坛、匿名爆料、小报、传闻类、未署名转录）/ 关键细节缺失。
- **L4**：无法确认（找不到来源、记忆性说法、时间地点人物对不上）。
- 只有 L0 能写"确定/已证实"。L1-L3 必须带限定词（"据…报道""多源一致但未核原始""单一传记记载""存在矛盾"）。**L4 只进未确认问题清单，不得进事实正文。**

## 3. 条目格式（统一，便于 Lead 合并去重）
每个信息点一行，Markdown 表格，列固定：

`| ID | 信息点 | 内容（具体、含英文原文） | 类型 | 置信 | 来源 | 需用户确认 | 阻塞/非阻塞 |`

- **ID**：`<文件码>-<三位序号>`，如 `S1-001`、`S2-014`。
- **类型**：只能是 `事实` / `原话` / `推断` / `风险` / `问题` 之一（可组合如 `事实+推断`，推断部分必须写明"推断"）。
- **来源**：`S-xxx`（S1 建立的编号）+ 具体位置（页码/章节/时间戳/段落），例如 `S-012（Isaacson 传 p.84）`。S1 尚未完成时，先写 `[来源名+URL]`，Lead 会统一映射编号。
- **需用户确认**：`是/否`。只有真正需要用户拍板的才写"是"。
- **阻塞**：`阻塞`（不确认就不能定稿）/ `非阻塞`。

## 4. 来源真实性（防编造，最重要）
- 每条来源必须是你**实际搜索到/抓取到**的真实 URL。**严禁编造、拼接、猜测 URL**。
- 无法打开的链接标 `取用状态=未打开`；只有搜索摘要没正文的标 `仅见摘要`。
- 书籍来源必须给：作者、书名、出版年、页码或章节（无页码标"未核页"）。
- 引文严禁改词。英文原话逐字保留（含原文大小写与标点），中文译文另起。**无出处的一律写"转述"，不得加引号。**

## 6. 数量下限（宁多勿少，但要具体，不许灌水凑数）
S1 ≥40 来源；S2 ≥25 节点；S3 ≥30 条原话；S4 ≥15 条边界/风险项；S5 ≥20 条背景条目；S6 覆盖第一波全部关键条目；S7 3-5 个主题 + ≥8 条空白。

## 7. 收工回报格式（≤150 字）
`文件：<路径>｜条目数：N｜高置信(L0/L1)：n｜L3/L4：n｜阻塞问题：<无 或 一句话>`

## 8. 事实基调提醒
对象已于 2011 年去世，今天是 2026-11-04：所有生平事件均为历史，可交叉核验；但**不得把他人的回忆录说法当作事实**，也不得把"传闻已久"默认成真。矛盾处照实记录两边说法，不要抹平。
