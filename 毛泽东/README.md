# 毛泽东（Mao Zedong）人物调查

- **调查对象**：毛泽东 / Mao Zedong（1893-12-26 ~ 1976-09-09），字润之，湖南湘潭韶山冲人；中国共产党、中国人民解放军、中华人民共和国主要缔造者
- **调查日期**：2026-11-06，**v1.1（用户原件补充版）**
- **调查口径**：仅公开信息；中立全景（1893–1976，含革命时期与建国后）；允许公开可查的负面与争议，但必须多源并列并标置信度；社媒/匿名帖一律 L3 且不作事实定稿；保留外文原始来源
- **调查方式**：8 个协作 agent 分波（来源搜集 → 时间线/画像 → 原话/观点 → 边界/敏感 → 时代背景 → 事实核验 → 主题与空白 → 合成与质检），**未做任何前采**，全部依据公开材料

## 一句话结论

从韶山农家子弟到共和国主要缔造者，以农民动员与武装割据取胜的战略家，也是晚年以阶级斗争治国、发动"文革"造成严重灾难的最高领导人（**L2**，评价性综合，非事实断言）。

## 报告里已拦截的常见误传（详见附录 D）

- "中国人民从此站起来了"被系于 1949-10-01 开国大典 —— 原句在 1949-09-21 政协开幕词，FLP 英译篇目与正文均确证（**L4** 场合误置）
- "与天斗，其乐无穷" —— 可核版为"与天奋斗"，脱"奋"字版是网络变体（奋斗版 **L1**／斗版 **L4**）
- "知识越多越反动" —— 毛审定文本零命中，文革后期极端化概括（**L4**）
- "人有多大胆，地有多大产" —— 1958-08-27《人民日报》署名文章标题（作者刘西瑞），非毛语（**L4**）
- "两个凡是" —— 1977-02-07 两报一刊社论，非毛文字（**L4**）
- "感谢日本皇军" —— 官方文本为 1961-01-24"我宁愿感谢日本军阀"并附上下文；"皇军"版系拼接（原文 **L1**／皇军版 **L4**）
- "中国非死一半人不可" —— 被指裁掉"压缩指标""以不死人为原则"等上下文（**L2** 断章争议）
- "我一生干了两件事"长版本 —— 《毛泽东年谱》编者注"没有查到档案根据"（短版 L3／长版 **L4**）
